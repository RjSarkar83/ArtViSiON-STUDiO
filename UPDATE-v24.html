2CMYK PDF — press ke liye

Pro output → CMYK PDF — aam RGB PDF ki jagah asli CMYK, ink limit ke saath.

  • Har pixel C / M / Y / K alag channel me (GCR + 300% total ink limit = press safe).
  • Page = asli print size + bleed + crop marks, MediaBox / TrimBox / BleedBox set.
  • 300 dpi image, /DeviceCMYK + FlateDecode compression — file chhoti.
  • File name: <design>-CMYK-300dpi.pdf
Imaandaar baat: conversion browser me hoti hai (GCR approximate). Exact press profile (jaise ISO Coated v2) chahiye to printer se match karayein. Screen / WhatsApp ke liye normal Print Pack (.zip) hi best hai.

3Multi-copy sheet (N-up)

Ek sheet par jitni copies fit hoti hain + har copy par crop marks — card, sticker, label, tag.

  • Sheet: A4 · A3 · Letter (default A4) · copies: Auto (max) ya 4…30.
  • Live mini preview — column × row aur copies per sheet turant dikhta hai (Visiting Card par A4 = 2×4 = 8 copies).
  • Output: single-page PDF, hairline crop marks, trim-accurate placement.
  • File name: <design>-sheet-A4-8up.pdf
