Sirf patch nahi — asli wajah pakdi gayi, phir fix kiya gaya.

Aap ne kahaAsli wajahv22 fix
1. Selection delete nahi hoti, kuch bhi delete nahi hota App me copy/cut/paste ka handler hi nahi tha. Delete sirf vector shapes par chalta tha — pixel selection aur layer dono ignore. Delete ab smart: pehle selection ke pixels, warna poora layer. Raster + vector layer delete (key, layer panel, ☰ Menu) — sab undo-able.
2. Marquee / lasso se copy-cut-paste nahi Marquee aur lasso sirf mask banate the; mask ke andar ka content copy karne ka code maujood hi nahi tha. Ctrl+C / Ctrl+X / Ctrl+V — marquee, lasso, wand sab par. Paste naya "Pasted" layer banata hai (original safe) aur pasted hissa auto-selected aata hai.
3. Selection ke andar fill / feather / grow / shrink / adjust Andar ka code (jaise deleteSelectionPixels) tha, lekin UI se reachable nahi tha — na button, na shortcut. Bar me Fill · Grow · Shrink · Feather · Invert · Layer · Adjust. Ctrl+U aur Image → Adjust Colors sirf selection ke andar lagta hai.
4. Wand se select karne par kuch dikhata nahi Wand/marquee selection ban jata tha, par koi control surface nahi — user ko lagta tha kuch hua hi nahi. Floating Selection bar (px count + 12 buttons) selection bante hi neeche aa jata hai; Ctrl+D / Done par chala jata hai.
Bonus fix: Move tool se selection ke andar drag karne par ab selection ka content move hota hai (float) — pehle poora layer khisak jata tha. Enter = commit, Esc = safe commit, Ctrl+Z = undo.

Kaise use karein — 3 step

  1. Select karo — M marquee, L lasso, ya W magic wand.
  2. Neeche bar dekho — Fill / Delete / Copy / Cut / Paste / Grow / Shrink / Feather / Invert / Layer / Adjust / Done.
  3. Move tool (V) se andar drag = content move, Enter = fix, Ctrl+D = deselect.
